## Security and operations review

- Trusted proxy: use one loopback Nginx hop, `TRUST_PROXY_HOPS=1`, and overwrite
  `X-Forwarded-For` with the edge-observed address. Do not expose Node ports or
  trust arbitrary proxy chains. The default global rate limit is 120/60s and the
  Identity controller uses 20/60s; both are in-memory per API process. Document
  preview/download and letter-template download enforce `UNDUH_LIMIT_ANONIM`
  per anonymous IP and `UNDUH_LIMIT_PENGGUNA` per authenticated user in a
  one-hour fixed window. Limit overflow returns 429 without buffering streams.
  Authorization precedes counting/opening, so unauthorized Secret probes remain
  not-found and do not consume the authorized download quota.
- The rapid browser route sweep exceeded the Identity controller's 20 requests
  per 60 seconds and received expected `429` responses from `auth/me`. The
  protected routes remain fail-closed, but repeated route visits within the
  window can show a temporary session-status error. The authenticated Admin UI
  still needs its planned smoke test with an approved test account and normal
  navigation cadence.
- Security headers: **CSP enforcement DONE.** Next sets an enforced nonce-based
  CSP plus `nosniff`,
  `SAMEORIGIN`, `strict-origin-when-cross-origin`, and a restrictive
  Permissions-Policy. Production CSP has no wildcard, `unsafe-inline`, or
  `unsafe-eval`; development alone permits `unsafe-eval` for its debug runtime.
  Same-origin API calls, Google auth navigation/form target, and blob PDF preview
  are accounted for. **Download rate-limit enforcement DONE** for authorized
  document/template streams. Nest Helmet protects API responses; API CSP is
  disabled because API does not render HTML. Nginx adds HSTS after HTTPS
  verification.
- Privacy: no API/UI projection sends `storage_key` or absolute storage paths.
  Audit UI omits payload snapshots, request IDs, IP/user-agent and credentials.
  Session/Google tokens and cookies are redacted from logs. CSRF proof is
  returned only to the same-origin frontend through `auth/me` for required
  write protection; it is not rendered, persisted to browser storage, or logged.
- Health: public liveness/readiness returns status without database exception
  detail, private storage path, or OS error. This was tightened and tested during
  this pass.
- Performance: public/admin search and list queries use page size caps and SQL
  `LIMIT/OFFSET`; search/count filters visibility in SQL. Public home requests
  latest public item rather than loading an entire dataset. File streams use
  Node streams and are not buffered fully in application memory. No large load
  benchmark was run; substring metadata search has no full-text PDF index.
